# 华夏未来：中国文明手机版

**Huaxia Future Mobile · 1.1.0**

适用于原版 Unciv 的中文扩展模组，提供中国文明强化、现代军事、未来科技和星际胜利。无需修改游戏客户端或安装桌面补丁。规则与素材通过 Unciv 4.22.6-patch1 桌面引擎验证；Android设备实测尚待完成。

## 手机下载

在 Unciv 首页进入「模组」，刷新可下载列表，搜索 **Huaxia Future Mobile** 并下载。

也可以选择「从URL下载模组」，粘贴：

```
https://github.com/zjmnb66611/Huaxia-Future-Mobile
```

下载后新建游戏，基础规则选 **Civ V - Gods & Kings**，扩展模组只勾选 **Huaxia Future Mobile**，玩家选择 **中国**。发布后的仓库需要被GitHub搜索索引收录才会出现在列表，直接URL下载不依赖列表搜索结果。

## 歼36手机版设定

| 项目 | 数值或效果 |
| --- | --- |
| 文明 | 中国专属，替代隐形轰炸机 |
| 轰炸战斗力 | 145 |
| 基础防御战斗力 | 85 |
| 攻击范围 | 40格，原版隐形轰炸机为20格 |
| 航母搭载 | 支持，可调动到己方航母，并随舰移动；遵守航母容量 |
| 空中拦截伤害 | 减少95% |
| 解锁 | 隐形技术、铝；基础造价425生产力 |
| 图标 | 原创灰色无尾三角翼透明图标 |

**145表示轰炸战斗力，不是最终伤害固定增加70%。** 145由85×1.7取整得到；最终伤害仍由游戏按目标防御、血量、晋升和随机因子计算。这是作者确认采用的原版手机兼容方案。

手机版的95%减伤作用于「拦截」伤害。轰炸防空单位本身时产生的普通反击按原版规则结算；桌面版Java补丁中的额外反击减伤和最终伤害乘法未包含在本手机版中。

## 整合内容

- 中国特性「薪火相传」：保留原版大将军能力，增加农场粮食与科研建筑生产加成。
- 12种新增单位：99A主战坦克、歼20、055型驱逐舰、191型远程火箭炮、歼36，以及未来步兵、机甲、轨道炮、无人机和巡洋舰。
- 12项未来科技，2个未来时代：数智时代、星际时代。
- 10项建筑与项目，包括太学、综合工业区、国家科学园、量子研究中心、聚变发电站、轨道太空港和星海方舟计划。
- 新增星际胜利：完成未来科技主线，在具备聚变发电站、轨道太空港的城市建造星海方舟。

若想完整体验未来阶段，可在新建游戏时只保留星际胜利与征服胜利，避免原版胜利条件过早结束游戏。

不要与 China Plus、People s Republic of China、The Best Future、Future Worlds、Future Expansion、Warfare Expanded 或桌面 Huaxia Future Pack 同时启用；它们会覆盖同一套规则。手机版使用独立模组名称，避免桌面补丁与145战斗力叠加。

## 素材和验证

随包包含可在Android直接读取的预打包图集。单位图标和FantasyHex、HexaRealm、Minimal地图歼36素材路径已准备；其他新增单位、建筑、科技复用原版同类图标。

详细作者和许可见 [CREDITS.md](CREDITS.md)。制作与验证只使用独立内存对局，没有操作玩家存档。验证报告在仓库之外单独保存；不把桌面测试当作手机实测。

游戏数值为模组设定，不表示现实装备性能。
