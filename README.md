# 华夏未来：中国文明手机版 1.2.0

本包为Gods & Kings的中文扩展，提供中国强化、现代军事、未来科技、15个独立现代世界奇观和星际胜利。1.2.0保留歼36的145轰炸战斗力、40格射程、航母搭载和95%拦截减伤。

## 本版修改

- 未来科技改为三条相邻列分支，增加行星协同节点，最后在单独一列汇合到星际文明，消除本包同列依赖与跨节点长线。
- 13个新增单位均有独立黑色透明剪影；更新三套地图素材路径。15个现代奇观均有独立地标剪影。
- 所有新增世界奇观在原版信息时代科技下解锁，所有文明均可竞争建造，不替换原版奇观，也不要求中国文明。
- 世界奇观使用Huaxia前缀避免第三方同名对象覆盖。国家大剧院等额外收益、地形限制均为游戏设定。
- 预打包单一图集，可由Android原生客户端读取；清除已废弃的灰色歼36图集、重复源图和根目录构建清单。

## 模组组合与安装

基础规则选择 **Civ V - Gods & Kings**。只选择下列一个华夏版本，先勾选第三方模组，再最后勾选所选华夏版本。

| 使用的其他模组 | 选择的华夏版本 |
|---|---|
| 原版，或Cityes Expanded、Extra Buildings、Warfare Expanded Lite | Huaxia Future Mobile |
| Future Expansion Continued，可同时添加上述建筑/军事扩展 | Huaxia Future Mobile Continued |
| Future Worlds，可同时添加上述建筑/军事扩展 | Huaxia Future Mobile Worlds |

三个版本包含同样的单位与15个奇观；区别是未来科技起始列、依赖关系和Continued的太空项目生产加成。安装时，手机可以将对应ZIP的公开直链粘贴到模组界面的「从URL下载」。不要同时勾选三个华夏版本，也不要同时勾选Future Worlds和Future Expansion Continued；它们会覆盖同一批原版科技。标准版明确阻止这两种未来扩展，请改选对应兼容版。

兼容性验证针对本工作区第三方文件快照。组合引擎加载没有引入新的规则问题；Warfare Expanded Lite和Future Expansion Continued自身已有的旧规则警告未被本包修复。未承诺任意模组或后续所有第三方版本兼容。声音扩展没有被本包主动禁止，但本轮未做手机播放测试。

## 东风导弹

中国专属核导弹，替代Nuclear Missile，高级弹道学解锁。核爆强度4（原版2），爆炸半径4格（原版2；按最后确认设定），射程4096格覆盖原生生成器允许的常规地图，原生Cannot be intercepted免拦截，发射后消耗。保留曼哈顿计划和2铀需求，成本1800。

核爆强度是等级参数：强度大于2会摧毁可被摧毁的普通城市，原始首都受保护；单位核爆伤害与城市人口损失依照原生分支，不是所有目标扣血固定乘2。600战斗力是原版300的2倍，但核爆效果实际取决于强度和半径。全球核打击仍需已探索目标，不要求当前可见，受外交限制；极端手工导入的非标准超大地图只覆盖4096格。

## 歼36与验证范围

歼36为中国专属隐形轰炸机替代单位，轰炸战斗力145、防御85、射程40格，可登舰并随舰移动，遵守航母容量。95%减伤仅作用于空中拦截；轰炸防空单位本身的普通反击仍按原版规则结算。145不是最终伤害固定乘1.7。

独立内存对局使用Unciv 4.22.6-patch1桌面真实引擎，无Java代理、不读写玩家存档、不启动游戏窗口。验证覆盖规则/素材、15项奇观选址的正反案例、全国金币/文化/科研加成、世界唯一性，东风导弹的远程核打击、拦截免疫、核爆强度和4格半径，以及歼36航母行为。手机实机与最终游戏界面仍待用户设备检验，附带科技树图片为布局预览，不是游戏截图。
